# Treasury Payment Control Tower — Dashboard (public, code-only)

Static, offline, client-side-only dashboard for the AP Payment Control
Tower workflow (parsing, reconciliation, ERP export). No financial data
is stored in this repo or this page — all files are uploaded and
processed entirely in the visitor's own browser and never leave it.

Live: https://tultc4.github.io/treasury-payment-dashboard/

This is a mirror of the dashboard file from the private project repo
(`ap-payment-control-tower`), published separately so it can be hosted
via GitHub Pages.
